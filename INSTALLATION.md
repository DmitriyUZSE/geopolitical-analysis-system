## ЧТО УЛУЧШИЛОСЬ

### 1. **Cascade Engine (js/cascade-engine.js)**

**Было:** ~10 правил, встроенных в HTML  
**Стало:** **70+ правил** в отдельном модуле

**Новые возможности:**
- ✅ Экономические правила (15 правил)
- ✅ Политические правила (18 правил)
- ✅ Безопасность (12 правил)
- ✅ Ресурсы и гео-экономика (8 правил)
- ✅ Социальные факторы (5 правил)
- ✅ Межакторные взаимодействия (6 правил)
- ✅ Обнаружение петель обратной связи (3 паттерна)

**Примеры новых правил:**

```javascript
// Если экономическая диверсификация падает
economic_diversification ↓ → fiscal_resilience ↓

// Если режим теряет легитимность
regime_legitimacy ↓ → social_contract ↓ → domestic_security ↓

// Если военные возможности растут
military_capability ↑ → fiscal_resilience ↓ (милитаризация дорогая)

// Межакторное: если один наращивает военную мощь
Actor_A.military ↑ → Actor_B.military ↑ (гонка вооружений)
```

### 2. **Стили (css/styles.css)**

**Было:** Всё в `<style>` внутри HTML  
**Стало:** Отдельный CSS файл

**Новые фичи:**
- Адаптивный дизайн (работает на телефонах)
- Анимации (плавные переходы)
- Тёмная тема (автоматически если в системе включена)
- Стили для печати (удаляет ненужное при печати)
